State

A typed node for one path in a player's data. Every field in your template is a node, and every node has the same few methods. Everything is dot syntax: nodes hand out pre-bound functions, so S.Coins.Get() works with no self. The one exception is a node's Changed signal, which is a real object: S.Coins.Changed:Connect(fn). 

local Data = require(game.ReplicatedStorage.Data).Server

local S = Data:LoadVault(Player)
if S then
	S.Coins.Update(function(Coins)
		return Coins + 50
	end)
	S.Inventory.AddNext("Sword")

	-- Fires once with the current value, then on every change
	S.Coins.Observe(function(Coins, Old)
		print("Coins:", Coins, "was", Old)
	end)

	-- Only on changes
	local Connection = S.Coins.Changed:Connect(function(New, Old)
		print(New, "was", Old)
	end)
	Connection.Disconnect()
end

All nodes: Get, Set, Update, Observe, Changed Tables: Mutate, Snapshot Maps and arrays: Has, Keys, Values, Size, Clear Maps: Insert, Remove Arrays: AddNext, RemoveLast, InsertAt, RemoveAt Root only: IsLoaded, Save, End, Replicate, GetSessionInfo, GetMeta, SetMeta

Write methods throw on the client. Change data on the server and let replication do the rest.

Type solver required

Autocomplete needs the new Luau type solver. Runtime works without it.

Properties​

Changed​

</>
State.Changed: Signal

A signal that fires when this node's value changes. Unlike State.Observe it does not fire for the current value on connect.

It's a real object, so it uses method syntax.

local Connection = S.Coins.Changed:Connect(function(New, Old)
	print(New, "was", Old)
end)

S.Coins.Changed:Once(function(New) end)
local New, Old = S.Coins.Changed:Wait()

Functions​

Get​

</>
State.Get() → T--

The value at this node, or nil if there is none.

Returns the current value at this node.

On the client, tables are read-only proxies unless ClientGuard is "Off".

local Coins = S.Coins.Get()
local Stats = S.Stats.Get()

Mutate​

Tables
</>
State.Mutate(
Mutator: (Target: T) → ()--

Receives the table to change in place.

) → ()

Changes several fields of a table at once. Strata works out what changed and replicates only that. Throws on the client.

S.Stats.Mutate(function(Stats)
	Stats.Level += 1
	Stats.Xp = 0
end)

Observe​

</>
State.Observe(
Listener: (
Value: T,
Old: T?
) → ()--

Called with the new value and the old one.

) → Connection--

Call Disconnect on it to stop listening.

Calls a function with this node's value now and every time it changes.

The listener runs once shortly after you connect, with the current value and a nil old value, then on each change with the new and old values. Values that haven't changed don't fire again.

Observing a parent fires when any child changes, and observing a child fires when its parent is replaced. Use State.Changed if you only want changes.

local Connection = S.Stats.Level.Observe(function(Level, Old)
	print("Level is", Level)
end)

Connection.Disconnect()

Remove​

Maps
</>
State.Remove(
Key: string | any--

The map key to remove (not a numeric array index).

) → any--

The value that was removed, or nil if the key was missing.

Removes one key from this map. Throws on the client.

For arrays, pass a string key only if the array is being used as a map. Numeric indices on array-like tables must use State.RemoveAt or State.RemoveLast — removing by number would leave a gap in the sequence. 

S.Items.Remove("sword_001") -- map
S.Inventory.RemoveAt(2) -- array
S.Inventory.RemoveLast() -- array

Debug
</>

A shallow copy of the path array. Empty at the root.

Returns the path segments from the vault root to this node.

Useful when writing generic helpers or logging which field changed.

print(table.concat(S.Stats.Level.GetPath(), ".")) -- "Stats.Level"
