Strata

This item only works when running on the client. ClientThis item only works when running on the server. Server

Data, without the overhead.

Strata isn't the data system with the most features. It's the one that asks the least of you to get a great one. Describe your data once and Strata loads it, saves it, replicates it to the client and types it for you. Built on ProfileStore. 

-- ReplicatedStorage/Data
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Strata = require(ReplicatedStorage.Strata)

local template = {
	coins = 0,
	stats = { level = 1 },
	inventory = {} :: { string },
}

return Strata({
	storeName = "Players",
	template = template,
	leaderstats = { coins = true },
})

-- server
local Data = require(game.ReplicatedStorage.Data).server
local S = Data:loadVault(Player)
if S then
	S.coins.update(function(coins)
		return coins + 25
	end)
	S.inventory.addNext("Wooden Sword")
end

-- client
local Data = require(game.ReplicatedStorage.Data).client
local C = Data:loadVault()
if C then
	C.coins.observe(function(coins)
		print(coins)
	end)
end

ReplicateMode​

</>
type ReplicateMode = "diff" | "full" | "hybrid"

How changes reach the client.

  • "hybrid" (default) sends small patches and switches to a full snapshot when a frame queues too many of them.
  • "diff" sends patches.
  • "full" always sends the whole table.

ClientGuard​

</>
type ClientGuard = "proxy" | "off"

Whether tables returned by get on the client are protected.

  • "proxy" (default) returns read-only tables that throw when written to.
  • "off" returns the raw table.

SessionOptions​

</>
interface SessionOptions {
incognito: boolean?--

If true, the session never saves (manual, auto, or on end).

key: string?--

Fully override the save key for this load.

keyPrefix: string?--

Override the store keyPrefix for this load only (applied before UserId / PlayerKey).

}

Per-load options for StrataServer.loadVault / StrataServer.getVault.

-- Never saves
Data.server:loadVault(Player, { incognito = true })

-- Saves under a fixed key
Data.server:loadVault(Player, { key = "QA_Profile_01" })

-- Load a specific key, but never write back
Data.server:loadVault(Player, { incognito = true, key = "Template_Starter" })

Config​

</>
interface Config {
storeName: string--

The DataStore name. Required.

template: T--

The shape and default values of a player's data. Required.

leaderstats: Flags<T>?--

Top-level number, string or boolean fields to show on the leaderboard.

private: PrivateFields<T>?--

Fields that are saved but never sent to the client, at any depth.

transient: TransientFields<T>?--

Fields that live in memory only and are never saved, at any depth.

keyPrefix: string?--

Prepended to the UserId to build save keys. Defaults to "".

playerKey: ((Player) → string)?--

Full control over save keys. Defaults to keyPrefix .. UserId.

mock: boolean?--

Use ProfileStore's in-memory storage. Nothing is saved. Defaults to false.

kickOnFail: boolean?--

Kick players whose data fails to load. Defaults to true.

kickOnSessionEnd: boolean?--

Kick players when their session ends while they are in the server. Defaults to true.

kickMessage: string?--

The message shown when a player is kicked.

loadTimeout: number?--

Seconds loadVault waits before returning nil. Defaults to 30.

schemaVersion: number?--

The current schema version. Pair with StrataServer.bindToMigrate.

autoSaveSeconds: number?--

Extra save interval on top of ProfileStore's own auto-saving.

replicateMode: ReplicateMode?--

How changes reach the client. Defaults to "hybrid".

maxPatchesBeforeFull: number?--

Patches per frame before a full snapshot is sent instead. Defaults to 24.

collapsePatchesAt: number?--

Changed keys in one table before it is sent as a single patch. Defaults to 12.

flushImmediately: boolean?--

Send each change right away instead of batching. Defaults to false.

replicateOnSave: boolean?--

Send a full snapshot after each manual save. Defaults to false.

clientGuard: ClientGuard?--

Whether client tables are read-only. Defaults to "proxy".

validate: boolean?--

Check every write and refuse anything DataStores can't save (sparse arrays, mixed keys, NaN, bad UTF-8). Defaults to true.

}

The options passed when calling the Strata module. Only storeName and template are required.

Mutation and session hooks are signals on StrataServer, not options.

PrivateFields<T>​

</>
type PrivateFields<T> = {[string]: boolean | PrivateFields<T>}

Fields that are never sent to the client. Mirrors your template at any depth: secret = true hides a root field, stats = { antiCheat = true } hides one field inside a table, and stats = true hides the whole table. Missing keys default to false.

TransientFields<T>​

</>
type TransientFields<T> = {[string]: boolean | TransientFields<T>}

Fields that live in memory only and are never saved. Mirrors your template at any depth: session = true marks a root field, combat = { combo = true } marks one field inside a table, and combat = true marks the whole table. Each session starts them from the template. Missing keys default to false.
