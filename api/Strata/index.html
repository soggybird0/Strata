Strata

This item only works when running on the client. ClientThis item only works when running on the server. Server

Data, without the overhead.

Strata isn't the data system with the most features. It's the one that asks the least of you to get a great one. Describe your data once and Strata loads it, saves it, replicates it to the client and types it for you. Built on ProfileStore. 

-- ReplicatedStorage/Data
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Strata = require(ReplicatedStorage.Strata)

local Template = {
	Coins = 0,
	Stats = { Level = 1 },
	Inventory = {} :: { string },
}

return Strata:Init({
	StoreName = "Players",
	Template = Template,
	Leaderstats = { Coins = true },
})

-- server
local Data = require(game.ReplicatedStorage.Data).Server
local S = Data:LoadVault(Player)
if S then
	S.Coins.Update(function(Coins)
		return Coins + 25
	end)
	S.Inventory.AddNext("Wooden Sword")
end

-- client
local Data = require(game.ReplicatedStorage.Data).Client
local C = Data:LoadVault()
if C then
	C.Coins.Observe(function(Coins)
		print(Coins)
	end)
end

ReplicateMode​

</>
type ReplicateMode = "Diff" | "Full" | "Hybrid"

How changes reach the client.

  • "Hybrid" (default) sends small patches and switches to a full snapshot when a frame queues too many of them.
  • "Diff" sends patches.
  • "Full" always sends the whole table.

ClientGuard​

</>
type ClientGuard = "Proxy" | "Off"

Whether tables returned by Get on the client are protected.

  • "Proxy" (default) returns read-only tables that throw when written to.
  • "Off" returns the raw table.

The options passed to Strata:Init. Only StoreName and Template are required.

PrivateFields<T>​

</>
type PrivateFields<T> = {[string]: boolean | PrivateFields<T>}

Fields that are never sent to the client. Mirrors your template at any depth: Secret = true hides a root field, Stats = { AntiCheat = true } hides one field inside a table, and Stats = true hides the whole table. Missing keys default to false.

TransientFields<T>​

</>
type TransientFields<T> = {[string]: boolean}

Root fields that live in memory only and are never saved. Each session starts them from the template. Missing keys default to false.
