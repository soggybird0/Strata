StrataClient

This item only works when running on the client. Client

The client side of a Strata store: a read-only replica of the local player's data. It has the same State surface as the server, but anything that writes throws. Change data on the server and let replication do the rest.

Get it from Strata.Init as Data.Client.

local Data = require(game.ReplicatedStorage.Data).Client

local C = Data:LoadVault() -- yields until the first replica arrives
if C then
	print(C.Coins.Get())
	C.Coins.Observe(function(Coins)
		CoinLabel.Text = tostring(Coins)
	end)
end
