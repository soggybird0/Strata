StrataClient

This item only works when running on the client. Client

Client replica of a Strata store. Same State surface as the server, but writes error (mutate on the server only).

Functions​

Open​

</>
StrataClient.Open(Options: Config<T>) → StrataClient<T>

Opens or retrieves a client replica for a Strata store.

Creates a client replica if one does not already exist. Subsequent calls for the same store reuse the existing replica.

The returned client automatically requests its initial data and receives subsequent replication updates.

LoadVault​

</>
StrataClient.LoadVault(self: StrataClient<T>) → State<T>?

Waits for the initial replica to become available. Returns the State instance once the replica has loaded. Returns nil if the configured loading timeout is reached.

GetVault​

</>
StrataClient.GetVault(self: StrataClient<T>) → State<T>?

Retrieves the existing client replica without waiting.

Returns nil if the replica has not loaded yet.

IsLoaded​

</>
StrataClient.IsLoaded(self: StrataClient<T>) → boolean

Checks whether the client replica has loaded.

GetSettings​

</>
StrataClient.GetSettings(self: StrataClient<T>) → CachedSettings

Retrieves the cached configuration for this client store.

</>
StrataClient.RequestSyncAPI(self: StrataClient<T>) → ()
