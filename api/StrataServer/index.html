StrataServer

This item only works when running on the server. Server

The server side of a Strata store. It manages every player's session: sessions load when a player joins and end when they leave, so you never write PlayerAdded or PlayerRemoving handlers for data.

Get it from Strata.Init as Data.Server.

local Data = require(game.ReplicatedStorage.Data).Server

Players.PlayerAdded:Connect(function(Player)
	local S = Data:LoadVault(Player) -- yields until loaded
	if S then
		S.Coins.Update(function(Coins)
			return Coins + 5
		end)
	end
end)

LoadVault​

This item only works when running on the server. ServerThis is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
StrataServer:LoadVault(
Target: string | Player--

A player, or a string key for data that is not tied to a player.

) → State<T>?--

The vault, or nil if it could not load.

Returns the vault for a player, waiting until their data is ready.

Returns nil if the data could not load: the player left, or LoadTimeout ran out. Always check the result.

local S = Data.Server:LoadVault(Player)
if S then
	print(S.Coins.Get())
end

local Guild = Data.Server:LoadVault("Guild_42")
