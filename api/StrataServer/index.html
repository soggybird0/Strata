StrataServer

This item only works when running on the server. Server

Server session manager. Public surface: LoadVault, GetVault, IsLoaded, GetSessionInfo, GetSettings, ForEachSession. Sessions load/end automatically for every player.

Functions​

Open​

</>
StrataServer.Open(Options: Config<T>) → StrataServer<T>

Initializes a server store and its session manager.

Creates the underlying ProfileStore and automatically manages player sessions, saving, replication, and cleanup.

LoadVault​

</>
StrataServer.LoadVault(
self: StrataServer<T>,
Target: Player | string
) → State<T>?

Loads or retrieves a player's data vault.

Waits for the session to become available before returning its State interface. Returns nil if the session cannot be loaded or the loading timeout is reached.

Accepts either a Player or a string session key.

GetVault​

</>
StrataServer.GetVault(
self: StrataServer<T>,
Target: Player | string
) → State<T>?

Retrieves an existing data vault without waiting.

Returns nil if the session has not loaded or is no longer active.

Accepts either a Player or a string session key.
